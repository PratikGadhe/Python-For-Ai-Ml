# AI/ML Learning Repository

This repository is a structured learning workspace for Python, data science, and AI/ML foundations. It contains practice code, library notes, and topic-wise folders for building a strong base in machine learning and deep learning.

## Repository Structure

- `BASIC_PYTHON/` - Python basics, chapter-wise practice, and problem-solving exercises.
- `Numpy/` - NumPy fundamentals, arrays, dimensions, operations, saving arrays, and practice examples.
- `Pandas/` - Pandas basics including Series, DataFrames, and CSV handling.
- `Matplotlib/` - Data visualization examples including line charts, bar charts, and histogram practice.
- `Basic Math for ML/` - Math concepts required for machine learning.
- `Machine Learning/` - Machine learning algorithms, practice files, and notes.
- `Deep Learning/` - Deep learning concepts and future neural network practice.
- `Scikit-learn/` - Scikit-learn examples and model-building practice.
- `PyTorch/` - PyTorch learning and deep learning implementation practice.
- `SeaBorn/` - Seaborn visualization examples.
- `SQL/` - SQL practice for data handling and querying.
- `Projects/` - AI/ML mini-projects and applied practice work.

## Goal

The goal of this repository is to keep AI/ML learning organized from Python basics to advanced machine learning topics. Each folder focuses on one important area so concepts can be practiced step by step.

## How To Run Python Files

From the repository root, create or activate a virtual environment and run files using Python:

```bash
python3 -m venv .venv
source .venv/bin/activate
python Numpy/07_practice.py
```

Install required libraries as needed:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn torch
```
